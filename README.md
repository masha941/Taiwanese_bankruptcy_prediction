# Taiwanese Bankruptcy Prediction
 
Projekat analize i predviđanja bankrota tajvanskih kompanija.

Dataset: https://archive.ics.uci.edu/dataset/572/taiwanese+bankruptcy+prediction

## O projektu
 
Model analizira finansijske atribute kompanija i predviđa da li će kompanija bankrotirati.  
 
Analiziranih modela: Logistic Regression, Decision Tree, Random Forest, KNN, SVM  
Evaluacija: Accuracy, Recall, Precision, F1, ROC-AUC, Precision-Recall krive, 5-Fold CV
